# ADR 0001. FE와 BE를 한 저장소에 둔다

- 상태: 확정
- 날짜: 2026-11-15

## 배경
프런트(Next.js)와 백엔드(Spring Boot)를 1인이 함께 개발한다.

## 선택지
1. 저장소 분리 (frontend / backend 각각)
2. 한 저장소에 디렉터리로 분리 (모노레포)

## 결정
2번. `frontend/`, `backend/`를 한 저장소에 둔다.

## 이유
- 기능 하나를 만들 때 API와 화면 변경을 한 PR로 묶을 수 있다.
- 포트폴리오 링크가 하나로 정리된다.
- CI는 `paths` 필터로 바뀐 영역만 실행해 비용을 줄인다.

## 감수하는 점
- 저장소 단위 권한 분리가 불가능하다. (1인 프로젝트라 문제 없음)
