# 기능 명세

## 서비스 한 줄 소개
두독(DooDok)은 다 읽은 책을 다음 독자에게 넘기고, 그 책에 남긴 감상(독후감)을 함께 전하는 중고책 거래 서비스다.

## 핵심 흐름
1. 판매자가 책을 등록한다. (ISBN/제목 검색 → 도서 정보 자동 입력, 거래 방법 선택)
2. 판매글에 자신의 독후감을 첨부할 수 있다.
3. 구매자는 독후감 기반 추천과 검색으로 책을 찾고, 매물이 없으면 서재에 담아 입고 알림을 받는다.
4. 채팅으로 조율하고, 판매자가 채팅 상대 중 한 명을 골라 예약 → 거래 완료한다.
5. 거래가 끝나면 서로 거래 후기를 남긴다.
6. 구매자가 다 읽고 독후감을 남긴다 → 다시 판매로 이어진다.

## MVP 범위

| 영역 | 기능 | 우선순위 |
|---|---|---|
| 회원 | 회원가입, 로그인(JWT), 내 정보 | P0 |

| 매물 | 판매글 CRUD, 사진 업로드(S3 Presigned URL), 상태 등급, 거래 방법(직거래/택배/둘 다) 선택, 검색·필터 | P0 |
| 독후감 | 독후감 CRUD(같은 책 여러 번 가능), 공개 여부, 스포일러 표시, 판매글 첨부 | P0 |
| 내 서재 | 읽고 싶은 책 / 읽은 책, 매물 등록 시 입고 알림 | P0 |

| 거래 | 판매자가 채팅 상대 중 예약자 선택, 예약·완료·취소, 동시 예약 방지 | P0 |
| 거래 후기 | 거래 완료 후 서로 평가 (좋아요/보통/별로), 프로필에 표시 | P0 |
| 알림 | 채팅·거래·후기·입고 알림, 실시간 전달(SSE) | P0 |
| 시세 | 도서별 최근 거래가, 정가 대비 비율 | P1 |
| 인기 순위 | 인기 매물·도서 (Redis Sorted Set) | P1 |
| 독후감 공감 | 독후감 좋아요 | P2 |
| 신고·차단 | 신고, 차단, 관리자 처리 | P2 |
| AI | 독후감 기반 도서 추천 (임베딩 + 하이브리드) | P0 |
| AI | 대화형 도서 추천 (Tool Calling) | P1 |
| AI | 월간 독서 리포트 | P1 |

## 제외한 기능과 이유
- **책 대여**: 반납·연체·파손 분쟁 처리가 범위를 크게 늘린다. 거래 + 독후감에 집중한다.
- **결제(PG 연동)**: 개인 간 거래로 두고, 거래 상태 관리에 집중한다.
- **배송 추적**: 택배 거래도 송장 번호는 채팅으로 주고받는다.
- **동네 인증·위치 기반 검색**: 직거래 장소는 판매자가 자유롭게 적는다.
- **모바일 앱**: Flutter 앱 출시 경험이 이미 있어, 이번에는 반응형 웹으로 대신한다.
- **MSA / Kafka / Kubernetes**: 1인 프로젝트 규모에서는 과설계. 모놀리스를 잘 나누는 데 집중한다.

## AI 기능 설계 원칙
- 숫자(통계, 가격)는 SQL로 계산하고, LLM은 해석 문장만 만든다.
- LLM은 백엔드 함수(Tool) 결과 안에서만 답한다. 존재하지 않는 책을 만들지 않는다.
- 임베딩은 쓰기 시점에 비동기로 한 번만 만들고, 모델 버전을 함께 저장한다.
- 사용자 글(독후감)이 LLM 입력에 들어가므로 프롬프트 인젝션을 고려한다.
- 출력은 JSON 스키마로 검증하고, 실패 시 재시도 → 폴백한다.
